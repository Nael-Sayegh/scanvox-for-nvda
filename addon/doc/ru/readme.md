# Презентация

Это дополнение использует программу Scanvox для чтения ваших бумажных документов. Оно было создано с помощью разработчика программы и не требует дополнительной установки.

## Необходимые условия 

Для использования этого дополнения к компьютеру должен быть подключён USB-сканер, совместимый с TWAIN или WIA, что характерно для большинства сканеров.

## Как это работает

Чтобы использовать это дополнение, перейдите в меню NVDA и выберите Scanvox. В этом диалоге вы можете начать сканирование, нажав на кнопку Сканировать. Начало сканирования займёт несколько секунд, а по окончании процесса отсканированный текст будет автоматически прочитан вслух. Вы можете отключить автоматическое воспроизведение, перейдя в меню настроек NVDA, а затем в категорию scanvox для NVDA. Нажимайте эту кнопку до тех пор, пока не будут отсканированы все страницы. Если вы хотите удалить только что отсканированную страницу, вы можете нажать кнопку "удалить последнюю отсканированную страницу", расположенную рядом с кнопкой "сканировать", перейдя к ней при помощи клавиши tab или нажав сочетания клавиш alt+l. После завершения сканирования вы можете прочитать отсканированные страницы, выполнив shift+tab от кнопки сканирования или alt+t для перехода к редактору с содержимым всех страниц. В этом редакторе, если вы хотите быстро переходить со страницы на страницу, вы можете использовать кнопки "Предыдущая страница" и "следующая страница" или сочетания клавиш ctrl+shift+ стрелка вверх и ctrl+shift+стрелка вниз. Вы можете сохранить файл при помощи соответствующей кнопки.
Если вы хотите удалить отсканированные страницы, чтобы отсканировать новый документ, вы можете нажать кнопку Удаление всех отсканированных страниц.
При выходе из Scanvox все отсканированные страницы будут удалены.

### Сочитания клавиш

Дополнение "Scanvox для NVDA" можно запустить из любого места на вашем компьютере, нажав nvda+alt+s. Этот жест можно изменить в диалоге  жесты ввода.
